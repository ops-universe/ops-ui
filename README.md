# ops-ui

Reusable React components and design tokens for Ops Universe. Developer Preview, not published to npm.

```sh
npm install
npm test
```

Import from a reviewed local checkout or pinned Git revision after installing dependencies. Import `@ops-universe/ui/styles.css` alongside components. React 18/19 peer dependency. Theme provider supports system/light/dark, persisted preference and reduced-motion CSS. Header, Hero, Card, Footer and native button/link controls are included; full search, responsive navigation menus, browser accessibility testing and package publication remain pending. A lockfile must be committed before a reproducible release.
