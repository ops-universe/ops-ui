# Project palettes

Use `ThemeProvider` with `project="evalOps"` (case insensitive). Unknown project names fall back to Universe. All colors use semantic tokens for both themes. Add a unique preset with contrast tests before launching a new project. The palette registry is exported from the library. Browser accessibility remains a separate gate.
